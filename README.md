## 🌟 मुख्य विशेषताएं (Core Features)
1. **100+ परीक्षाएं व 57 पोर्टल्स:** सर सी.वी. रमन, रामानुजन, NMMS (7 राज्य), नवोदय, सैनिक स्कूल, सिमुलतला SAV, OBC कन्या आवासीय, BSEB 10th/12th, UP Board, पॉलिटेक्निक, ITI, मेधासॉफ्ट, और प्रमुख ई-पेपर्स (हिन्दुस्तान, प्रभात खबर)।
2. **AI डेट व समरी पार्सर (Groq AI):** सर्कुलर व लेखों से असली अंतिम तिथि (Deadlines), परीक्षा तिथि और 2-लाइन हिंदी समरी 1.2 सेकंड में निकालना।
3. **हेडलेस स्क्रीनशॉट (Playwright):** सरकारी वेबसाइट्स का लाइव स्क्रीनशॉट खींचकर टेलीग्राम अलर्ट और यूट्यूब थंबनेल के लिए तैयार रखना।
4. **Zero-Duplicate Guarantee:** SHA-256 हैश और MongoDB यूनिक इंडेक्स के कारण एक ही खबर छात्रों को दो बार कभी नहीं जाएगी।
5. **पुराने साल का रिजेक्शन:** 2023 या 2024 के पुराने नोटिस को AI खुद पहचानकर रिजेक्ट कर देता है।

## 🚀 लोकल में कैसे चलाएं (How to Run Locally)

